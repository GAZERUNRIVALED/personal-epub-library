# Personal EPUB Library v2.0

Perpustakaan novel EPUB pribadi berbasis browser (Client-Side Static Web App) dengan dukungan penyimpanan **IndexedDB**, kompatibilitas **HTML5 ekspor Legado** & **XHTML standar**, optimasi **6.000+ chapter**, serta fitur **Split EPUB**.

## Penting Mengenai Penyimpanan Lokal (IndexedDB)
- Seluruh file `.epub`, cover, metadata, dan riwayat baca disimpan **100% di penyimpanan lokal browser perangkat Anda** (IndexedDB).
- Tidak ada file novel yang dikirim ke server, GitHub, atau Cloudflare Pages.
- Karena bersifat lokal, koleksi di Chrome Android tidak otomatis tersinkronisasi ke browser desktop. Gunakan fitur **Backup / Restore** untuk memindahkan metadata dan progres baca antar perangkat.
